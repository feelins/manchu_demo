## 用法

### 页面验证

1. 启动服务：`./scripts/services.sh start`
2. 打开 `http://127.0.0.1:8000/ocr/`
3. 上传本目录任意图片 → 点「古籍AI识别」或「正楷AI识别」

### 命令行回归

```bash
curl -X POST http://127.0.0.1:8000/api/ocr/recognize \
  -F "image=@docs/samples/ocr/asj212a.jpg" \
  -F "model_type=ancient" \
  -F "recognize_chinese=0"
```

预期：`layout_used=true`、`columns` 非空（5 列满文）、`column_thumbs` 与列数一致。
