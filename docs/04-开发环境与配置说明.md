## 7. 常驻部署（gunicorn + systemd，2026-09-29）

`nohup python app.py &` 只能"手动后台跑"：进程挂了不会回来，重启机器要记得拉。
现在改成 **gunicorn 管进程，systemd 管生死**。

### 7.1 三个文件

| 文件 | 作用 |
|---|---|
| `gunicorn.conf.py` | 运行参数：2 worker × 4 线程、`gthread`、`timeout 600`、日志落 `logs/gunicorn-*.log` |
| `run.sh` | 启停脚本：`前台`（systemd 用）/ `start`（后台兜底）/ `stop` / `restart` / `status` |
| `deploy/systemd/manchu-portal.service` | 单元文件模板：`Restart=always`（5s 后自愈）、日志进 journal |

### 7.2 安装（首次）

```bash
mkdir -p ~/.config/systemd/user
cp deploy/systemd/manchu-portal.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable manchu-portal      # 开机自启
systemctl --user start  manchu-portal
```

日常只用：`systemctl --user restart manchu-portal`（改完代码按这句即可）。

### 7.3 开机自启的前置条件：linger

用户级 systemd 的实例在你**登录桌面之后**才起来。要做到「机器开机、人不登录也常驻」，需要管理员执行一次：

```bash
sudo loginctl enable-linger leyesi        # 输入的密码是你自己的 sudo 密码
loginctl show-user leyesi | grep Linger   # 确认变成 Linger=yes
```

**当前状态：`Linger=no`**——即现在是「登录桌面后自动起来」，尚未做到无人值守自启。

拿不到 sudo 时的兜底（`run.sh start` 自带端口占用判断，重复执行安全）：

```bash
crontab -e
@reboot sleep 20 && /home/leyesi/shaopf/manchu_demo/run.sh start
```

### 7.4 参数为什么这么定

- **`timeout=600`**：门户会把 OCR / TTS 请求转发给后端再回源，单次可达数分钟
  （`/api/tts/` 自身 gateway timeout 就是 600）。worker 超时若小于它，请求会被
  gunicorn 从中间掐断，前端表现为"合成到一半报 502"。
- **`worker_class=gthread`**：门户大部分时间耗在等后端，属 IO 密集；
  用线程模型比堆进程省内存，也避免每个 worker 重复初始化。
- **`debug` 必须关**：`FLASK_DEBUG=1` 才会打开 Werkzeug 调试器，对外等于开放远程代码执行。

## 8. 满文字体：内嵌方案（2026-09-30）

字体文件：`static/fonts/buleku.woff2`（48 KB）+ 原 `001A-Buleku-R.ttf`（153 KB，兜底）。
声明位置：`static/css/manju-font.css`，由 `templates/base.html` 引入——**所有页面模板都继承 base.html，
因此改这一处即全站生效，不需要在每个页面重复内嵌。**

### 为什么是"内嵌"而不是引用字体文件

原先是 `@font-face { src: url("/static/fonts/*.ttf") }`。字体走**独立的 HTTP 请求**，
一旦被网络策略拦下或加载慢，浏览器就回退到 `serif`，满文显示为方块/错字——
远程访问（aTrust 等）环境下尤其容易触发。

改为 **woff2 base64 内嵌**后，字体数据随 CSS 一起到达（CSS 本来就要加载，必然可达），
不再依赖额外请求。与「满语文平台_内嵌字体版.html」的处理方式一致。

代价：CSS 63 KB（base64 膨胀约 33%），但浏览器会缓存该文件，只有首次传输。

### 如何换字体

1. 拿到 woff2（或 TTF）；
2. 覆盖 `static/fonts/buleku.woff2`；
3. 重新生成 CSS：
   ```bash
   python3 -c "
   import base64, pathlib
   b = pathlib.Path('static/fonts/buleku.woff2').read_bytes()
   pathlib.Path('static/css/manju-font.css').write_text(
       '@font-face{font-family:\"Buleku\";'
       'src:url(data:font/woff2;base64,%s) format(\"woff2\"),'
       'url(\"../fonts/001A-Buleku-R.ttf\") format(\"truetype\");'
       'font-weight:normal;font-style:normal;font-display:swap;}' % base64.b64encode(b).decode()
   )"
   ```
4. `systemctl --user restart manchu-portal`（模板/CSS 改动后要重启才会生效）。

> 字体名统一为 `Buleku`；`design-token.css` 的 `--manju` 回退链是
> `Buleku → Mongolian Baiti → serif`，各页面直接用 `var(--manju)` 即可。
