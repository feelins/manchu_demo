## 2. 目录结构（当前，阶段 1 后）

```
manchu_demo/
├── app.py                # Flask 入口：create_app() + 上下文变量 + 占位路由
├── config.py             # 站点信息 / 导航 / 页脚 / 首页数据（数据驱动外壳）
├── requirements.txt      # Flask>=3.0
├── .gitignore            # .venv/ __pycache__/ *.pyc
├── .venv/
├── templates/
│   ├── base.html         # ★ 统一外壳（head/字体/主体/页脚 + block content）
│   ├── index.html        # 首页（extends base.html）
│   ├── placeholder.html  # 模块占位页（extends base.html）
│   └── partials/{header,footer}.html
├── static/
│   ├── css/design-token.css   # ★ 设计令牌（配色/字体/圆角/阴影）
│   ├── css/base.css           # 外壳 + 通用组件（机构条/导航/页脚/区块/卡片/标签）
│   ├── css/home.css           # 首页专属（Hero/流水线/数据卡/工作平台）
│   └── fonts/001A-Buleku-R.ttf
├── docs/
└── logs_app.log
```

**约定**
- 新页面一律 `{% extends "base.html" %}` 并填 `{% block content %}`；页面级样式放 `{% block extra_css %}`。
- 颜色/间距/圆角一律用 `design-token.css` 里的 CSS 变量，禁止在页面中写死色值。
- 导航、页脚、首页数据集中在 `config.py`，模板不做硬编码。

## 5. 配置约定（待落地 `.env` / `config.py`）

```ini
MANJU_ENV=dev            # dev | prod | demo
PORT=8000

# 各模型服务地址（前端永远只写 /api/...，由门户转发）
OCR_RECOGNIZE_URL=http://127.0.0.1:1000
OCR_DETECT_URL=http://127.0.0.1:7860
TRANSLATE_URLS=8001,8003,8005
TTS_URL=http://127.0.0.1:7868
ASR_URL=

# 演示保障
DEMO_MODE=off            # off | on（on 时所有推理走预置结果）
CACHE_BACKEND=file       # file | redis
STORAGE_BACKEND=local    # local | minio | oss
```

**硬约定**：
1. 前端**不允许**出现 `localhost:端口`，只用 `/api/<module>/...` 相对路径；
2. 第三方库（jszip / mammoth 等）本地化到 `static/vendor/`，不依赖 CDN；
3. 时区 `Asia/Shanghai`、编码 UTF-8；
4. 满文⇄拉丁规则引擎**全站只有一份实现**（`common/manju_rules.py`）。
